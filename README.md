# Dodge & Survive

[![Live demo](https://img.shields.io/badge/demo-live-19336e?style=flat-square)](https://hellenicdev.eu/dodge-and-survive/) [![License: BSD 3-Clause](https://img.shields.io/badge/license-BSD%203--Clause-blue?style=flat-square)](LICENSE)

A fast-paced 2D arcade game built with HTML5 Canvas. Dodge falling enemies, shoot them down and collect power-ups to survive as long as possible.

**Play it live:** <https://hellenicdev.eu/dodge-and-survive/>

## Features

- Increasing difficulty the longer you survive
- Shooting, lives and shield power-ups
- High score saved in your browser
- On-screen touch controls on phones and tablets
- Pauses automatically when you switch tabs
- Music and sound effects

## How to play

- **Arrow keys / A, D**: move left and right
- **Space**: shoot
- **P**: pause
- **R** or click: restart after game over (tap on mobile)

## Run locally

No build step. Serve the folder with any static server:

```sh
git clone https://github.com/hellenicdev/dodge-and-survive.git
cd dodge-and-survive
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Tech

- HTML5 Canvas, CSS3 and vanilla JavaScript
